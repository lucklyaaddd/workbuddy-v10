# WorkBuddy V10.0 部署操作手册

## 一、Supabase 项目创建

### 1.1 创建项目
1. 访问 https://supabase.com → 注册/登录
2. 点击 New Project → 填写项目名称 `workbuddy`
3. 设置数据库密码（妥善保存）
4. 选择地区：Southeast Asia (Singapore) 或最近地区
5. 点击 Create new project 等待初始化完成

### 1.2 获取 API 密钥
1. 进入项目 → Settings → API
2. 记录以下信息：
   - **Project URL**: `https://xxxxx.supabase.co`
   - **anon public key**: 用于前端
   - **service_role key**: 用于后端（⚠️ 绝不暴露到前端）

### 1.3 关闭公开注册（⚠️ 安全必须）
1. 进入 Authentication → Settings
2. 找到 "Enable Sign Up" → 设为 **OFF**
3. 确认 "Enable Email Confirmations" 可按需开启
4. 在 Authentication → Users 中手动创建管理员账号

### 1.4 手动创建管理员账号
1. 进入 Authentication → Users
2. 点击 "Add user" → 填写邮箱和密码
3. 勾选 "Auto Confirm User"
4. 点击 Create user

## 二、数据库迁移

### 2.1 执行建表脚本
1. 进入 SQL Editor → New query
2. 复制 `supabase/migrations/001_init.sql` 全部内容粘贴
3. 点击 Run 执行
4. 确认输出：`WorkBuddy V10.0 数据库表结构创建完成（11张表）`

### 2.2 执行 RLS 策略
1. 新建 query，复制 `supabase/migrations/002_rls.sql` 粘贴执行
2. 确认输出：`RLS 策略创建完成（10张表 × 4条策略 = 40条策略）`

### 2.3 执行 Storage 配置
1. 新建 query，复制 `supabase/migrations/003_storage.sql` 粘贴执行
2. 确认输出：`Storage 桶 images 创建完成`

### 2.4 验证
在 Table Editor 中确认以下表已创建：
todos, transactions, couple_logs, memos, reminders, quotes, push_subscriptions, user_preferences, operation_logs, export_logs, cron_executions

## 三、Vercel 环境变量

在 Vercel 项目设置 → Environment Variables 中添加：

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `VITE_SUPABASE_URL` | Supabase 项目URL | `https://xxxxx.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | Supabase anon密钥 | `eyJhbGci...` |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase服务端密钥 | `eyJhbGci...` |
| `BARK_ENCRYPTION_KEY` | Bark加密密钥(64位hex) | `a1b2c3d4e5f6...` |
| `CRON_SECRET` | Cron任务鉴权密钥 | `your-random-secret` |
| `EXPORT_DAILY_LIMIT` | 每日导出上限 | `3` |

### 生成加密密钥
```bash
# 生成 BARK_ENCRYPTION_KEY（AES-256-GCM 密钥）
openssl rand -hex 32

# 生成 CRON_SECRET
openssl rand -base64 32
```

## 五、iOS 添加主屏幕教程

### 5.1 安装 Bark App
1. App Store 搜索 "Bark" 下载安装
2. 打开 Bark → 复制专属推送 URL
3. URL 格式：`https://api.day.app/你的专属key`

### 5.2 添加 PWA 到主屏幕
1. iPhone 打开 Safari（⚠️ 必须用 Safari）
2. 访问部署后的 Vercel 链接 `https://你的项目名.vercel.app`
3. 登录账号
4. 点击 Safari 底部分享按钮 → "添加到主屏幕"
5. 命名为 "WorkBuddy" → 添加

### 5.3 配置 Bark 推送
1. 从主屏幕打开 WorkBuddy
2. 进入 设置 → Bark 推送配置
3. 粘贴 Bark URL → 输入设备名称
4. 勾选隐私告知 → 保存并测试
5. 收到测试推送表示配置成功

### 5.4 iOS 16.2 兼容说明
- 本版本推送通过 Bark App 中转，不依赖 iOS Web Push API
- 兼容 iOS 16.2 及以上所有版本
- 锁屏、后台、静音状态均可接收推送
- 无需升级系统即可使用

## 七、部署到 Vercel

### 7.1 GitHub 仓库
```bash
# 初始化 Git
git init
git add .
git commit -m "WorkBuddy V10.0 初始版本"

# 创建 GitHub 私有仓库后
git remote add origin https://github.com/你的用户名/workbuddy-v10.git
git push -u origin main
```

### 7.2 Vercel 部署
1. 访问 https://vercel.com → 登录
2. 点击 "Add New Project" → 导入 GitHub 仓库
3. Framework Preset 选择 **Vite**
4. 配置环境变量（参考第三章表格）
5. 点击 Deploy

### 7.3 配置 Cron Jobs
Vercel 部署完成后，Cron Jobs 会自动从 `vercel.json` 读取配置：

| 任务 | UTC时间 | 北京时间 | 频率 |
|------|---------|----------|------|
| 待办超时标记 | 16:30 | 00:30 | 每天 |
| 待办定时推送 | 每小时整点 | 每小时整点 | 每小时 |
| 智能提醒轮询 | 每小时整点 | 每小时整点 | 每小时 |
| 月度备份提醒 | 00:00 (1日) | 08:00 (1日) | 每月1日 |
| 农历年度刷新 | 17:00 (12/31) | 01:00 (1/1) | 每年 |
| 回收站清理 | 17:00 | 01:00(次日) | 每天 |

## 八、密钥轮换机制

### 8.1 轮换周期
- `BARK_ENCRYPTION_KEY`：建议每 6 个月轮换
- `CRON_SECRET`：建议每 3 个月轮换
- `SUPABASE_SERVICE_ROLE_KEY`：建议每年轮换

### 8.2 轮换 BARK_ENCRYPTION_KEY 步骤
1. 生成新密钥：`openssl rand -hex 32`
2. 编写迁移脚本：读取所有 push_subscriptions，用旧密钥解密 endpoint，用新密钥重新加密
3. 更新 Vercel 环境变量
4. 执行迁移脚本更新数据库
5. 验证推送功能正常

### 8.3 轮换 CRON_SECRET 步骤
1. 生成新密钥：`openssl rand -base64 32`
2. 更新 Vercel 环境变量
3. 自动生效（下次 Cron 调用使用新密钥）

## 九、常见问题

### Q: 推送收不到？
1. 检查 Bark App 是否在前台运行过一次
2. 检查 iOS 设置 → 通知 → Bark 是否允许通知
3. 在设置页面点击"测试推送"验证

### Q: 图片上传失败？
1. 检查 Supabase Storage 桶是否创建
2. 检查 RLS 策略是否正确
3. 确认图片大小 ≤ 200KB（前端自动压缩）

### Q: 离线数据不同步？
1. 检查网络连接
2. 进入设置手动触发同步
3. 如有冲突，按弹窗提示选择版本
